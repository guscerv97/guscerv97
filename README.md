## 🔨 O que venho construindo

Cada projeto abaixo marca um estágio da minha trilha de estudos, do básico de manipulação de dados até API REST sobre banco relacional com ORM:

- **[Databridge](https://github.com/guscerv97/Databridge)**: pipeline de conversão JSON → DataFrame → validação → CSV, usando Pandas e NumPy
- **[Skycrawler](https://github.com/guscerv97/Skycrawler)**: coletor de dados meteorológicos via API, com persistência incremental em CSV
- **[Bibliotrack](https://github.com/guscerv97/Bibliotrack)**: sistema de gestão de biblioteca com banco relacional (SQLite), ORM assíncrono (SQLAlchemy), migrações versionadas (Alembic) e uma API REST (FastAPI) publicada, com autenticação e cadastro em lote

No trabalho, também mantenho o **[export-logistics-dashboard](https://github.com/guscerv97/export-logistics-dashboard)**: uma planilha compartilhada com dashboard executivo assistido por IA, substituindo a reconciliação manual de dados entre empresas por uma fonte única.
